# FloatNotes

Плавающий пузырь для Android (телефон и планшет): работает поверх любых приложений.

- пишешь или вставляешь текст и сохраняешь;
- пока печатаешь, ниже сразу показываются похожие сохранённые записи (понимает опечатки и части слов);
- тап по записи копирует её в буфер, долгий тап удаляет;
- картинки: кнопка «Файл» (галерея) или «Вставить» (скопированная картинка из буфера); тап по миниатюре копирует картинку;
- пузырь можно таскать пальцем, тап по нему открывает окно, кнопка «—» сворачивает обратно, «⏻» закрывает всё.

Всё хранится только на устройстве (notes.json и папка images во внутренней памяти приложения).

## Как получить APK

### Вариант А: Android Studio
1. Открой папку проекта (File → Open), дождись синхронизации Gradle.
2. Build → Build APK(s). Файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант Б: без компьютера с Android Studio (через GitHub)
1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки (ветка `main`).
2. Вкладка Actions → Build APK → Run workflow (или оно запустится само после загрузки).
3. Когда сборка зелёная, внизу страницы запуска в Artifacts скачай `FloatNotes-apk`, внутри `app-debug.apk`.

## Установка и первый запуск
1. Скопируй APK на телефон/планшет, установи (разреши установку из неизвестных источников).
2. Открой FloatNotes, нажми «1. Разрешить показ поверх других окон», включи переключатель для FloatNotes.
3. Вернись и нажми «2. Запустить пузырь». На Android 13+ разреши уведомления (нужны для работы в фоне).
4. Пузырь ✎ появится на экране. Закрыть: кнопка ⏻ в окне или «Стоп» в уведомлении.

## Если что-то не работает
- Пузырь не появляется: проверь разрешение «поверх других окон» и что экономия заряда не убивает приложение (в настройках приложения поставь «Без ограничений»).
- Вставка из буфера читает его, только когда окно FloatNotes открыто и в фокусе, это ограничение Android.
- Клавиатура перекрывает список: окно открывается сверху экрана, поле ввода всегда выше клавиатуры.
- Минимальная версия: Android 8.0 (API 26).

## Структура
- `OverlayService.kt` пузырь, окно, копирование/вставка, список
- `Store.kt` хранение заметок и картинок
- `Fuzzy.kt` нечёткий поиск
- `PickImageActivity.kt` выбор картинки из галереи
- `MainActivity.kt` экран разрешений и запуска
